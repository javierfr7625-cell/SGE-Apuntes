Guía de Inicio y Setup desde Cero (Estructura y Comandos)

"Crear proyecto en blanco", "Estructura de carpetas", "CLI commands"
Objetivo: Crear un proyecto Angular Standalone limpio en Ionic v8 sin archivos basura, generando la estructura de carpetas que exige el profesor (`models/`, `services/`, `pages/`, `components/`, `assets/`).

1. Comando de Creación Oficial (Terminal)

PowerShell / Bash
# 1. Crear proyecto blank en Angular Standalone (Sin módulos viejos)
ionic start mi-examen blank --type=angular --standalone

# 2. Entrar a la carpeta
cd mi-examen

# 3. Instalar Swiper para las diapositivas
npm install swiper

# (Opcional) Si el examen pide multilenguaje:
npm install @ngx-translate/core @ngx-translate/http-loader

2. Arquitectura de Carpetas Exigida

Crea estas carpetas dentro de src/app/ y src/assets/ para tener todo organizado según el criterio del profesor:

📁 Arquitectura de Carpetas Oficial (src/)
src/
├── app/
│   ├── common/
│   │   └── models/          ← Interfaces TypeScript / DTOs (ej: zelda.model.ts)
│   ├── components/          ← Componentes modulares (ej: menu/, header/)
│   ├── pages/               ← Pantallas enlazadas a rutas (ej: inicio/, materials/)
│   ├── pipes/               ← Pipes de búsqueda personalizada (ej: filtro.pipe.ts)
│   └── services/            ← Servicios HTTP y Toast (ej: zelda.service.ts, toast.service.ts)
├── assets/
│   ├── data/                ← Ficheros JSON locales de prueba (ej: menu.json)
│   ├── i18n/                ← Traducciones (es.json, en.json) si hay multilenguaje
│   └── images/              ← Imágenes (AmongUs.jpg, logo.png, etc.)
└── environments/
    └── environment.ts       ← URLBase de la API: https://botw-compendium.herokuapp.com/api/v3

Modal Inline con `willDismiss` y Retorno de Datos

"Botón que lanzará un modal", "Generar número aleatorio", "Toast Aceptar/Cancel"

materials.page.ts (Lógica de Dismiss)
randomNumber = signal<number>(0);

protected generateRandom() {
  const total = this.materials().length;
  if (total > 0) {
    this.randomNumber.set(Math.floor(Math.random() * total));
  }
}

protected onWillDismiss(event: CustomEvent) {
  if (event.detail.role === 'cancel') {
    this.toastService.showToast('Cancelado', 'danger');
  }
  if (event.detail.role === 'aceptar') {
    const item = this.materials()[this.randomNumber()];
    const nombre = item ? item.name : 'Elemento';
    this.toastService.showToast('Aceptado: ' + nombre, 'primary');
  }
}

Listas Infinitas (Infinite Scroll) con Bloqueo

"Infinite Scroll", "Paginación continua", "Bloquear al llegar al final"
infinite.page.ts
import { Component, inject, OnInit } from '@angular/core';
import { InfiniteScrollCustomEvent } from '@ionic/angular';
import { DataService } from '../../services/data.service';

export class InfinitePage implements OnInit {
  private dataService = inject(DataService);
  items: any[] = [];
  currentPage = 1;

  ngOnInit() {
    this.loadData();
  }

  loadData(event?: InfiniteScrollCustomEvent) {
    this.dataService.getItems(this.currentPage).subscribe({
      next: (res) => {
        this.items.push(...res.results);

        // 1. COMPLETAR SIEMPRE EL EVENTO
        event?.target.complete();

        // 2. DESACTIVAR AL LLEGAR AL FINAL DE LA COLECCIÓN
        if (event && res.total_pages === this.currentPage) {
          event.target.disabled = true;
          return;
        }

        this.currentPage++;
      },
      error: (err) => {
        console.error(err);
        event?.target.complete();
      }
    });
  }
}

import { Pipe, PipeTransform } from '@angular/core';

@Pipe({
  name: 'filtro',
  standalone: true
})
export class FiltroPipe implements PipeTransform {
  transform(lista: any[], texto: string, columna: string): any[] {
    if (!lista) return [];
    if (!texto || texto.trim() === '') return lista;

    const term = texto.toLowerCase();
    return lista.filter(item => {
      const val = item[columna];
      return val ? val.toString().toLowerCase().includes(term) : false;
    });
  }
}

import { inject, Injectable } from '@angular/core';
import { TranslateService } from '@ngx-translate/core';

@Injectable({ providedIn: 'root' })
export class TranslateConfigService {
  private translate = inject(TranslateService);

  initLanguage() {
    const saved = localStorage.getItem('lang') || this.translate.getBrowserLang() || 'es';
    this.translate.setDefaultLang(saved);
    this.translate.use(saved);
  }

  setLanguage(lang: string) {
    this.translate.use(lang);
    localStorage.setItem('lang', lang);
  }
}

Diseño para que solo se vea una linea en la descripcion de cada objeto.

Aplica truncado multilínea/unilínea con CSS con elipsis (...) para que los textos largos de descripción no descuadren los ion-item de la lista.

  1. En el archivo de estilos de la página (ej. src/app/pages/inicio/inicio.page.scss), añade la clase .descripcion.
  2. Aplica display: -webkit-box;, -webkit-line-clamp: 1; y -webkit-box-orient: vertical;.
  3. Añade overflow: hidden; y text-overflow: ellipsis; para forzar el corte con puntos suspensivos (...).
  4. En el HTML de la página (inicio.page.html), añade la clase al párrafo: <p class="descripcion">{{ objeto.description }}</p>.
